## Backend API Tests (cURL)

### Test Build Endpoint
```bash
TOKEN="<your_jwt_token>"
curl -X POST http://localhost:8000/api/portfolio/build \
  -H "Authorization: Bearer $TOKEN" \
  -F "theme=minimal" \
  -F "user_prompt=Modern portfolio"
```

Expected: `{"job_id": "...", "status": "completed", "portfolio_id": "..."}`

### Test Publish Endpoint
```bash
curl -X POST http://localhost:8000/api/portfolio/publish \
  -H "Authorization: Bearer $TOKEN"
```

Expected (free): `403 {"detail": {"error": "publish_requires_pro", ...}}`
Expected (pro): `200 {"status": "published", "site_url": "..."}`

### Test Checkout Endpoint
```bash
curl -X POST http://localhost:8000/api/billing/checkout \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"plan": "pro"}'
```

Expected: `{"order_id": "...", "amount": 49900, "key_id": "..."}`

### Test Subscription Endpoint
```bash
curl http://localhost:8000/api/billing/subscription \
  -H "Authorization: Bearer $TOKEN"
```

Expected: `{"tier": "free", "status": "active", "expires_at": null}`

## Troubleshooting

### "Failed to authenticate"
- Check GitHub OAuth credentials in .env
- Verify redirect URI matches: `http://localhost:3000/auth/github/callback`

### "Portfolio build failed"
- Check Gemini API key in .env
- Check GitHub token is valid
- Verify network connectivity

### "R2 upload failed"
- Check R2 credentials
- Verify R2 bucket exists and is public
- Check Cloudflare account is active

### "Razorpay payment not working"
- Check Razorpay test keys
- Verify frontend can load Razorpay script
- Check CORS allowed origins

### "Database connection error"
- Verify PostgreSQL is running
- Check DATABASE_URL in .env
- Ensure database `portfolioai` exists
